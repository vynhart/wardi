# Store Page

The HTML draft for store page is on store-draft.html.

## For seller

Store page is the main interface a seller interact
with to manage the list of product on their store.
When seller open their own store page, They should
be able to open "seller mode" of the page. In seller
mode:
- Seller can add a new product
- Seller can edit a product

When a seller open store page that is not theirs,
they should open it as if they are a buyer.

### Seller actions

- Go to "edit" mode.
- Click on "Add product" to go to add product screen.
- Click on "Edit product" to go to edit product screen.
    Edit product screen should use the same screen as
    add product, only the product id and names are
    pre-filled.

## For buyer

The purpose of store page for buyer is so that
buyer browse seller's product on store page.

### Buyer Actions
- Add the product to cart by tapping on 'plus' button. 
    Cart panel on bottom sheet should be updated automatically.
- Search product (Opened search product screen)
- Proceed to checkout by tapping on 'cart' button to
open cart page.
